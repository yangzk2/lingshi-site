# 产品路线图

> 节奏说明:每个阶段以「功能测试全绿 + 用户验收通过」为完成标准,验收通过即进入下一阶段;计划时间会随实际验收节奏调整。

## 当前能力(已交付)

**员工端 · 灵狮引擎**

- 桌面端(macOS / Windows)与网页版
- 局域网多端访问:手机 / 平板浏览器直连
- AI 对话、长任务执行、技能与插件体系
- 企业登录门:账号(人员 ID / 邮箱)+ 密码,未登录不可用核心功能

**管理端 · 灵狮后台**

- 知识库管理:文档库 / QA 库 / 知识空间统一视图
- 菜单级角色权限、登录体系(账号密码 / 邮箱)
- 品牌与主题配置

**平台底座**

- 统一网关:认证、授权、计量、审计
- 权限底座:组织级访问控制(ReBAC)、多租户隔离

## 阶段规划

| 阶段 | 主题 | 要做什么 | 达成目标 | 计划时间 | 状态 |
|---|---|---|---|---|---|
| 第二期 | 登录与组织体系 | 单点登录对接(企业微信 / 飞书 / 钉钉);组织架构树完善;角色权限矩阵用例全覆盖 | 员工用企业账号一键登录;权限按组织架构自动生效 | 2026 Q4 | 进行中 |
| 第三期 | 飞书式知识库 | 文档目录树、在线编写、所有者 / 协作者 / 分享、QA 对录入、Confluence 导入 | 企业知识像文档一样好写好找;权限变更实时生效、内容不落地员工电脑 | 2026 Q4 | 规划中 |
| 第四期 | 模型管理 | 内置模型统一下发;按组织层级逐级追加 / 删除;调用量、次数、费用计量与限额;员工自有外部模型隔离使用 | 管理员一键给全员发模型;费用可控、限额可查 | 2027 Q1 | 规划中 |
| 第五期 | 构建管理 | 工作流 / 工具 / MCP / 技能 / 连接器统一评测后分发;未过评测不可分发 | 企业自建能力「上架即评测、评测即可用」 | 2027 Q1 | 规划中 |
| 第六期 | 插件市场与运营闭环 | 插件市场、钉钉 / 宜搭 / 邮箱集成、跨通道审批闭环、全量审计、官网下载页与自动更新 | 插件可见即可用、权限变更自动生效;产品具备完整对外分发能力 | 2027 H1 | 规划中 |

## 长期原则

- 企业知识库内容不落地员工电脑
- 个人数据不出员工电脑
- 所有调用经企业网关统一认证、授权、计量、审计
