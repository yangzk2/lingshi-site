# 产品介绍

灵狮(LingShi)是面向企业内部的 AI 工作平台,由两部分组成:

## 灵狮引擎(员工端)

员工日常使用的 AI 助手,提供**桌面客户端**与**网页版**两种形态:

- AI 对话与长任务自主执行,支持多模态输入(图 / 文 / 文件)
- 技能与插件体系:工作流、MCP、连接器
- 企业知识库检索:按员工权限过滤
- 手机 / 平板浏览器可直连访问(同一局域网)
- 企业登录:统一账号(人员 ID / 邮箱)登录后才能使用核心功能

## 灵狮后台(管理端)

管理员统一管理组织、知识、模型与审批的运营后台:

- **组织与权限**:组织架构、角色权限(模块 / 菜单 / 按钮级)、用户与用户组
- **知识库管理**:文档库、QA 库、知识空间;在线编写、协作分享、Confluence 导入
- **模型管理**:内置模型统一下发、逐级授权限额、调用量与费用计量
- **构建管理**:工作流、工具、技能上架前评测,通过后分发全员
- **插件市场**:企业插件统一管理,员工可见即可用
- **审批中心**:与钉钉 / 宜搭双通道审批闭环
- **审计与看板**:全量审计日志、数据看板

## 三条产品原则

1. **企业知识库内容不落地员工电脑** —— 知识集中管理,按权限检索使用
2. **个人数据不出员工电脑** —— 员工自有数据与配置留在本地
3. **统一网关** —— 所有调用经企业网关认证、授权、计量、审计
